# 瘋狂審訊室

心理戰・語音審訊網頁遊戲。單人可以當審問官或嫌犯和電腦對戰；連線對戰可以和朋友各演一角，手機、電腦都能玩，找不到真人對手時自動改由電腦對戰。

遊戲製作：Eric Hu

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `server.js` | 連線對戰伺服器（房間、快速配對、回合計時、對手離線時改由電腦接手） |
| `package.json` | 伺服器需要的套件清單 |
| `public/index.html` | 遊戲畫面 |
| `public/engine.js` | 遊戲規則：五個案件、判斷問話、電腦審問官與電腦嫌犯、評分（伺服器和網頁共用） |
| `public/render.js` | 角色動畫：人類三種畫風＋六種動物，嫌犯和審問官的表情動作 |
| `public/music.js` | 背景音樂：三種曲風即時合成，隨嫌犯壓力變緊湊，破防與勝負有收尾音效 |
| `public/app.js` | 選單、單人與連線流程、語音、麥克風 |
| `dist/standalone.html` | 單人版（單一檔案，不需要伺服器，可以放在任何網站） |
| `build_standalone.py` | 修改 public 裡的檔案後，執行它重新產生單人版 |

## 上傳到 GitHub 並部署到 Render

1. 在 GitHub 建立新的儲存庫（例如 `crazy-interrogation`），把整個資料夾的檔案上傳上去（`node_modules` 資料夾不用上傳）。
2. 到 Render 選「New」→「Web Service」，連結剛才的儲存庫。
3. 設定：
   - Runtime：Node
   - Build Command：`npm install`
   - Start Command：`npm start`
4. 按下建立，部署完成後打開 Render 給你的網址就能玩，連線對戰也會自動啟用。

## 麥克風語音輸入

- 部署到 Render（網址是 https 開頭）之後，按麥克風就能用台灣中文問話，說完會自動送出。
- 建議使用 Chrome、Edge 或 Safari。第一次使用時瀏覽器會詢問是否允許麥克風，請按允許。

## 注意事項

- Render 免費方案閒置一段時間後會休眠，第一位玩家打開時要等大約半分鐘喚醒。
- 最高分紀錄存在玩家自己的瀏覽器裡，不會上傳到伺服器。
- 所有角色、背景、特效、音效和背景音樂都是程式即時產生的，沒有使用任何外部圖片或音樂素材，不會有版權問題。
